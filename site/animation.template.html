        Hash-chained ledger

        Each entry stores the hash of the entry before it. Changing any entry breaks every link after it.

        Research prototype from Spark AI NLP, Fredericton, New Brunswick, Canada. Classical, deterministic, standard-library Python. The OES-61440 model is a fixed set of uncalibrated thresholds, not a learned model and not a safety guarantee. Text screening catches copy-pasted attacks, not paraphrases; the runtime authorises and records but executes nothing.
