# Credits

## Portrait of Nikola Tesla

`site/assets/tesla-sarony-c1890.jpg` is used on the "Talk with the Tesla guide" page (`talk.html`) to show the historical person for context. The guide on that page is a fictional educational character, not the person in the photograph.

- Subject: Nikola Tesla (1856-1943), about age 34
- Photographer: Napoleon Sarony (1821-1896)
- Date: circa 1890
- Source: Wikimedia Commons, [File:Tesla_circa_1890.jpeg](https://commons.wikimedia.org/wiki/File:Tesla_circa_1890.jpeg) (the Commons page credits a postcard in the Tesla Museum, document no. MNT, VI/V 10, via RadioGraphics)
- Status: public domain. The Commons file page tags it `PD-old-100-expired` (the author died more than 100 years ago and the work was published before 1 January 1931).
- Changes: none apart from the 500-pixel-wide rendition served by Wikimedia (`.../thumb/7/79/Tesla_circa_1890.jpeg/500px-Tesla_circa_1890.jpeg`), downloaded 2026-10-18.

The photograph is public domain and is not covered by this repository's AGPL-3.0-only licence. It is not an AI-generated image.
